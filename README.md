# STATA-trust-and-military-spending-analysis
A quantitative study using STATA examining the relationship between level of trust in a country and the amount of money spent on the military. The results and analysis of the study are found in the pdf, with the files containing the source datasets in STATA format and the .do file script used to run the analysis. The file locations in the script would need to be changed to rerun it yourself. <br/> The source datasets are: The Development Indicators dataset produced by the World Bank in 2020; the World Values Survey dataset; and the Uppsala Conflict Data Program (UCDP)’s Armed Conflict dataset.
